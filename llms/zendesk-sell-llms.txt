# Zendesk Sell (Sales CRM) API

> Zendesk Sell (formerly Base CRM) is a sales CRM. Its REST API at https://api.getbase.com
> gives OAuth 2.0-authenticated CRUD access to leads, contacts, deals, notes, tasks, calls
> and custom fields, alongside a Sync API, a polled Firehose change stream and a Search API.
> IMPORTANT FOR AGENTS: Zendesk announced on 2025-09-09 that Zendesk Sell is retired on
> 2027-08-31, after which the product and its data are removed. Do not plan new long-lived
> integrations against this API.

Generated by API Evangelist from https://github.com/api-evangelist/zendesk-sell.
Zendesk publishes no llms.txt on its developer host (developer.zendesk.com/llms.txt -> 404).
A corporate marketing index does exist at https://www.zendesk.com/llms.txt (HTTP 200) but it
indexes zendesk.com content, not the Sell developer surface.

## Facts

- Base URL: https://api.getbase.com
- Version in path: https://api.getbase.com/{api-version}/{resource} — v2 core, v3 Firehose
- Auth: OAuth 2.0 bearer token; scopes read, write, profile
- Rate limit: 36,000 requests/hour per token (10 req/token/second); 429 on exhaustion; no rate-limit headers
- Required header: User-Agent (a request without one is rejected 400 invalid_user_agent)
- Pagination: page (1-based) + per_page (default 25, max 100)
- Errors: {"errors":[{"error":{code,message,details,resource,field}}],"meta":{http_status,logref}}
- Idempotency: none published; upsert endpoints match on business attributes instead
- Events: pull only — Firehose https://api.getbase.com/v3/:resource/stream. No webhooks.

## APIs

- [Zendesk Sell (Sales CRM) API](https://developer.zendesk.com/api-reference/sales-crm/introduction/): Core CRUD over leads, contacts, deals and the rest of the CRM graph.
- [Sync API](https://developer.zendesk.com/api-reference/sales-crm/sync/introduction): Stateful synchronization layer for keeping a local copy current. Premium.
- [Firehose API](https://developer.zendesk.com/api-reference/sales-crm/firehose/overview): Client-pulled change stream, 22 resources, 72-hour retention.
- [Search API](https://developer.zendesk.com/api-reference/sales-crm/search/introduction): Complex filters, sorts and aggregations over leads, contacts and deals.
